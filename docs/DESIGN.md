# WibeMusic — дизайн

Источник токенов: `web/src/index.css` (`@theme` и светлая тема внутри приложения). Этот документ описывает их; при расхождении правим код, затем документ.

## Цвета

| Токен | Тёмная тема | Светлая (в приложении) | Назначение |
| --- | --- | --- | --- |
| `--color-bg` | `#0b0b0b` | `#f6fbf3` | фон |
| `--color-surface` | `#161616` | `#ecf1ea` | карточки |
| `--color-raised` | `#212121` | `#e4eae2` | поля ввода, поднятые блоки |
| `--color-line` | `#2c2c2c` | `#d3dad1` | границы |
| `--color-fg` | `#f2f2f2` | `#181d18` | основной текст |
| `--color-muted` | `#a8a8a8` | `#535b53` | вторичный текст |
| `--color-dim` | `#6e6e6e` | `#737c73` | подписи, неактивные пункты |
| `--color-accent` | `#2dd4bf` | `#00796b` | основной акцент (мятно-бирюзовый) |
| `--color-accent-strong` | `#14b8a6` | `#005f54` | нажатие, усиленный акцент |
| `--color-on-accent` | `#000000` | `#ffffff` | текст на акценте |
| `--color-danger` | `#f26b63` | `#ba1a1a` | ошибки, опасные действия |

Вторичные цвета (`facet-1…5`, `warn`, `info`) используются только в графиках администратора и в обложках. Декоративных градиентов поверх данных нет.

## Контраст

Проверено вычислением по WCAG 2.x, без браузера:

- `#2dd4bf` на `#0b0b0b` ≈ 10.6:1 (текст и иконки проходят AA/AAA).
- `#00796b` на `#f6fbf3` ≈ 5.1:1 (проходит AA для обычного текста).
- `#a8a8a8` (muted) на `#0b0b0b` ≈ 8.3:1.
- `#6e6e6e` (dim) на `#0b0b0b` ≈ 3.9:1 — ниже AA для обычного текста. Использовать только для подписей крупнее обычного текста или вспомогательных надписей, не для важного текста.
- Текст на акценте `#000000` на `#2dd4bf` ≈ 11.3:1.

## Типографика

- Шрифт: Inter (вариативный, с кириллицей), поставляется локально в сборке.
- Заголовки крупные и жирные (`text-3xl font-bold` на входе); метаданные — `text-xs`/`text-[13px]`.

## Сетка и формы

- Отступы кратны 4 px (Tailwind-шкала).
- Радиусы: поля и кнопки `rounded-lg`, карточки `rounded-xl`.
- Поля ввода: класс `.input` (граница `--color-line`, фокус — акцент, `font-size: 16px` против зума на iOS).
- Интерактивные элементы около 44 px по высоте на телефоне (нижняя навигация 64 px).

## Движение

- Появление `anim-up` 0.18 s; скелетоны `skeleton` 1.2 s.
- При `prefers-reduced-motion: reduce` анимации выключаются (`index.css`).

## Оболочка

- Телефон и браузер: нижняя навигация `TabBar` (5 пунктов), фиксированная, `pb-safe`.
- Приложение Android (`?embedded=1`): навигация приложения, `TabBar` скрыт, `--tabbar-h: 0`.
- Светлая тема включается только внутри приложения (класс `hm-light`).

## Иконки

- Знак: зелёный круг заменён мятно-бирюзовым (`scripts/gen-icons.mjs`, `npm run icons`).
- Файлы: `web/public/icons/*` (PNG 192/512, maskable, badge 96, apple-touch 180, SVG).
- Внешние логотипы и эмодзи вместо иконок не используются.
