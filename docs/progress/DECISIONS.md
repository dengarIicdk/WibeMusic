# Решения

## D001 — развивать текущий frontend

Сохраняем React/TypeScript/Vite, собственный router и единый плеер. Это сохраняет совместимость со сложными сценариями волны, очереди и Android embedded-режимом. Новый дизайн реализуется существующими токенами и компонентами.

## D003 — AGENTS.md и игнорирование Git

Upstream `.gitignore` содержит `**/AGENTS.md`. Локальный `WibeMusic/AGENTS.md` работает для агента, но Git его не видит. Не меняем upstream `.gitignore` без поручения. Если понадобится хранить инструкцию в репозитории, добавим отдельное имя (например, `docs/progress/RESUME.md`) либо исключение `!AGENTS.md` после согласования.

## D002 — сохранять инфраструктурные идентификаторы

Бренд UI — WibeMusic; Compose project name, имена volumes, API и внутренние заголовки сохраняем. Изменение названия томов может скрыть существующие пользовательские данные. GPU и tunnel переводим в опциональные профили.
