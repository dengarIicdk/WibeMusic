## Выполнено (проверка кода, без изменений)

- Очередь (`web/src/lib/listen.ts`): `playNext`, `addToQueue`, `removeFromQueue`, `moveInQueue`, `playQueueAt`, `extendQueue`, `replaceUpcoming`, `next`, `prev`.
  - `removeFromQueue` не удаляет текущий трек и проверяет границы.
  - `moveInQueue` сохраняет индекс текущего трека после перестановки.
  - `playQueueAt` проверяет диапазон; нажатие на текущий трек переключает паузу.
  - `next` при `repeat=all` возвращается к началу, кроме волны (`onWave`).
- Плейлисты (`web/src/pages/Playlists.tsx`): создание с пустой проверкой имени, пустое состояние с объяснением, ошибка с повтором, скелетон при загрузке.
- Загрузки (`web/src/pages/Downloads.tsx`): фильтры «Все/Активные/Проблемы», пустые состояния для каждого фильтра, повтор и отмена, очистка готовых, живые обновления через `useHubEvent`, переподключение, карточки импортов.
- Состояния загрузки/пусто/ошибка: скелетоны, `Empty`, `ErrorState` с повтором — на экранах `MediaLibrary.tsx` и других.
