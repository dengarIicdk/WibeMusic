## Попытка установить Docker (зафиксирована)

- Docker Desktop 4.99.0 падал при установке (winget — код 1, официальный установщик — код -5), журнала с причиной нет. Полное удаление прошло, остатки удалены.
- WSL 3.0.5 установлен, но компонент «Подсистема Windows для Linux» (`Microsoft-Windows-Subsystem-Linux`) не найден в образе Windows 11 IoT Enterprise (сборка 22635): DISM возвращает 0x800f080c, `wsl --status` требует этот компонент. Virtual Machine Platform включён.
- Вывод: Docker в этой редакции Windows не работает без выяснения поддержки. Решение владельца — вариант 3: проверка без Docker, реальная приёмка позже в поддерживаемой среде.
